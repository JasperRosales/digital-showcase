# Digital Showcase

Digital Showcase is a student-friendly platform for discovering and sharing practical digital projects built by the community. Its purpose is to highlight useful apps, tools, and ideas that solve everyday problems, while giving creators a simple way to showcase their work.

## Why this project exists

The application helps students and visitors explore real examples of web-based solutions that are helpful, simple, and meaningful. It creates a space where innovative projects can be discovered, appreciated, and improved through collaboration.

## How to contribute

Contributions are welcome from anyone who wants to help improve the site or add a new app to the showcase.

1. Fork the repository and create a branch for your change.
   ```bash
   git clone https://github.com/your-username/digital-showcase-web.git
   cd digital-showcase-web
   git checkout -b add-my-app
   ```
2. Add your app details to the data/apps.json file with a short description, purpose, target audience, and other relevant information.
3. Place your app assets in the public/images/apps/ folder, such as an icon and screenshots.
4. Stage and commit your changes.
   ```bash
   git add data/apps.json public/images/apps/
   git commit -m "Add my app to showcase"
   ```
5. Push your branch to your fork and open a pull request for review.
   ```bash
   git push origin add-my-app
   ```

If you are adding a new project, make sure your entry is clear, well-described, and easy for others to understand. The goal is to make the showcase useful, welcoming, and inspiring for everyone.
